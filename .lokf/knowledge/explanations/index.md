# Explanations

* [Why one schema for two publications](why-one-schema.md) - Why this repository exists when lmodel/nist-ai-100-1 and lmodel/nist-ai-600-1 each model their publication: their adapt copies share elements, validate side by side and stop `lokf convert` with `Conflicting URIs`, so a host carrying both needs this copy.
* [The ISO/IEC 42001 crosswalk](the-crosswalk.md) - Why the AI RMF to ISO/IEC 42001 crosswalk is built on demand and never committed, what each SSSOM row claims, and how the builder reads the PDF: `skos:relatedMatch` rows, Annex B numbers read as Annex A controls, and three rows flagged.
* [What the repository leaves out](scope.md) - What this repository does not hold: a model of its own, the earlier fixtures derived from the Microsoft Agent Governance Toolkit, the earlier SSSOM set a matching tool wrote, and crosswalks whose targets have no lmodel schema.
