# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: whoever submits owns the contribution, a vendored file is never edited, the umbrella adds only what it says, a crosswalk's pair comes from its provider, and no commit carries an AI co-authorship trailer.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and the schema under Apache-2.0, the bundle under CC BY 4.0, NIST's publications under its statement, and the crosswalk, which states no licence and stays out of the repository. No endorsement by NIST is implied.
* [Security policy](security-policy.md) - How to report a vulnerability in this repository, by GitHub's private reporting, what executes here and what holds each surface. A problem in a model belongs with its repository, and one in NIST's text with NIST.
