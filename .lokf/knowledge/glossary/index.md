# Glossary

* [Adapt copy](adapt-copy.md) - An adapt copy: the copy of a published LinkML schema that `lokf adapt` writes so that it can sit beside LOKF's `lokf.yaml` in a domain schema, with its chosen roots on `Concept`.
* [Crosswalk](crosswalk.md) - A crosswalk: a table that pairs the elements of one framework with elements of another. Here it means the document that pairs AI RMF subcategories with ISO/IEC 42001 clauses and controls, written out as an SSSOM set.
